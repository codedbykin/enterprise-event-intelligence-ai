# Enterprise Event Intelligence Assistant

## What I built
An AI agent built for senior event managers
at world-class international venues.
Combines real event management expertise with
AI to handle every stage of event management.

## What it does
- Full budget breakdowns by event type and size
- Sponsorship package calculator with pricing tiers
- Risk assessment and mitigation planning
- Vendor negotiation tactics with market benchmarks
- Post-event report generator with ROI calculation
- Marketing channel ROI tracker
- Carbon footprint calculator with reduction strategies
- Crisis management guidance
- Timeline and milestone generator
- Client proposal generator

## Event types covered
Corporate conferences, gala dinners, award ceremonies,
product launches, Comic Cons, concerts, hybrid events,
exhibitions, graduations, charity galas

## Built with
- Microsoft Copilot Studio
- Custom knowledge base from 4+ years real
  event management experience
- GPT-5 Chat model
- Zero lines of code

## What makes this unique
Built by someone who actually managed large-scale
events at a premier international venue in Dublin
for over 3 years. The knowledge base reflects
real industry experience-not generic advice.

## AI advantage
What used to take an event manager hours
now takes minutes:
- Post-event reports: 4 hours - 15 minutes
- Budget breakdowns: 2 hours - 5 minutes
- Risk registers: 1 hour - 2 minutes
- Sponsorship pricing: guesswork - data-driven
